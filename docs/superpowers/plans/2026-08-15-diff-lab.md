# Diff Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a browser-only Diff Lab Vite app under LogicLoom (`/diff-lab/`) with DOCX entry picker, paste mode, and extensible preset/algorithm registries matching DiffCli v1 behavior.

**Architecture:** Thin React UI calls `recommend` + `runPreset`. Engine lives in `src/engine/` with `AlgorithmRegistry` and `PresetRegistry` maps. DOCX via JSZip; union entry list with available / not available.

**Tech Stack:** React 18, TypeScript, Vite 5, Vitest, JSZip; GitHub Pages via existing deploy workflow. No Railway.

**Spec:** `docs/superpowers/specs/2026-08-15-diff-lab-design.md`

## Global Constraints

- Hub path / Vite `base`: `/LogicLoom/diff-lab/`
- Preset ids (exact): `recommended`, `text`, `strict`, `ignore-ws`, `structured`
- DiffOp kinds (exact): `keep` | `del` | `ins` | `hdr`
- Missing DOCX entry: treat that side as `""` and show **not available** in UI (never silent blank)
- Entry list: **union** of both archives, alphabetical case-insensitive
- No backend in v1
- Port DiffCli Myers DP + XML/JSON flatten semantics from DiffMechanism `src/DiffCli/Program.cs`

### Task 3: Tokens + line/word presets (`strict`, `text`, `ignore-ws`)

**Files:**
- Create: `tokens.ts`, `presets.ts` (partial), `presets.test.ts`
- Modify: `registry.ts` — add `presetRegistry`, `registerPreset`, `runPreset`, `getPreset`

**Interfaces:**
- Consumes: `myersSes`, `DiffOp`, `Detection`
- Produces:
  - `splitLines(s: string): string[]` — normalize `\r\n`→`\n`; drop final empty segment if file ends with newline
  - `tokenizeWords(line: string): string[]` — words and each whitespace char as own token (DiffCli)
  - `leadingWsEqual(a: string, b: string): boolean`
  - `runPreset(id: string, a: string, b: string, detection: Detection): DiffOp[]`
  - Presets registered: `strict`, `text`, `ignore-ws` (and stub `recommended`/`structured` in Task 4)

**Pipeline behavior (match DiffCli):**
- `strict`: Myers on lines, ordinal equal
- `text` / `ignore-ws`: Myers on lines (ordinal vs leading-ws equal); for each adjacent del+ins pair with both non-empty and not equal under line comparer → emit `hdr` `~ modified line` then word Myers; else emit line ops

- [ ] **Step 1: Failing tests for splitLines + strict + word refine**

```ts
import { describe, it, expect } from 'vitest'
import { splitLines, tokenizeWords } from './tokens'
import { runPreset } from './registry'
import type { Detection } from './types'

const textDet: Detection = { kind: 'text', confidence: 'high', detail: 't' }

describe('tokens', () => {
  it('splitLines drops trailing empty after final newline', () => {
    expect(splitLines('a\nb\n')).toEqual(['a', 'b'])
  })
  it('tokenizeWords keeps spaces', () => {
    expect(tokenizeWords('hi there')).toEqual(['hi', ' ', 'there'])
  })
})

describe('presets strict/text', () => {
  it('strict treats indent-only change as full line replace', () => {
    const ops = runPreset('strict', 'x\n', '  x\n', textDet)
    expect(ops.some((o) => o.kind === 'del' && o.text === 'x')).toBe(true)
    expect(ops.some((o) => o.kind === 'ins' && o.text === '  x')).toBe(true)
  })

  it('ignore-ws keeps indent-only line as keep', () => {
    const ops = runPreset('ignore-ws', 'x\n', '  x\n', textDet)
    expect(ops).toContainEqual({ kind: 'keep', text: 'x' })
  })

  it('text word-refines modified line', () => {
    const ops = runPreset('text', 'return 1;\n', 'return 2;\n', textDet)
    expect(ops.some((o) => o.kind === 'hdr')).toBe(true)
    expect(ops.some((o) => o.kind === 'del' && o.text === '1;')).toBe(true)
    expect(ops.some((o) => o.kind === 'ins' && o.text === '2;')).toBe(true)
  })
})
```

### Task 4: Detect, recommend, JSON/XML flatten, `structured` + `recommended`

**Files:**
- Create: `detect.ts`, `detect.test.ts`, `flatten.ts`, `flatten.test.ts`
- Modify: `presets.ts` / `registry.ts`

**Interfaces:**
- Produces:
  - `detect(nameA: string, nameB: string, textA: string, textB: string): Detection`
  - `recommend(d: Detection): { id: string; reason: string }`
  - `flattenJson(json: string): string[]` — paths like `/user/age = 36`, object keys sorted ordinal
  - `flattenXml(xml: string): string[]` — attrs `@name`, text nodes, children `name[i]` (DiffCli)
  - Presets: `structured`, `recommended` (delegates to `recommend(d).id` then `runPreset`, never recurse on `recommended`)

**Detect rules:** extension from `nameA` then `nameB`; `.json` / looks `{`/`[`; `.xml` / looks `<`; `.html`/`.htm`; `.md`; else text. Valid parse → high confidence.

**Recommend:** json/xml → `structured`; html → `ignore-ws`; markdown → `text`; else `text`.

- [ ] **Step 1: Tests**

```ts
// flatten.test.ts
expect(flattenJson('{"b":1,"a":2}')).toEqual(['/a = 2', '/b = 1'])
expect(flattenXml('<root><item id="1">hi</item></root>')).toEqual([
  '/root/item[0]@id = 1',
  '/root/item[0] = hi',
])

// detect.test.ts
expect(detect('a.xml', 'b.xml', '<r/>', '<r/>').kind).toBe('xml')
expect(recommend({ kind: 'xml', confidence: 'high', detail: '' }).id).toBe('structured')
```

Also: `runPreset('structured', ...)` emits hdr `[structured XML paths]` and path-level del/ins; invalid XML falls back with hdr containing `structured` failure / unavailable → text.
